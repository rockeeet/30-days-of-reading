# 📚 30 Days of Reading

An Android app that encourages daily reading through bite-sized tips, a warm book-inspired design, and an easy-to-browse list of reading recommendations.

## ✨ Features

- Browse reading tips organized by day.
- Expand and collapse descriptions to explore each tip.
- Enjoy a custom interface with book-themed visuals and typography.
- Navigate a scrollable list of reading cards.

## 🛠️ Built With

- **Kotlin** — programming language
- **Jetpack Compose** — declarative UI toolkit
- **Material 3** — UI components and theming
- **Android Studio** — development environment

## 🚀 Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/rockeeet/30-days-of-reading.git
   ```
2. Open the project in Android Studio.
3. Wait for Gradle sync to finish.
4. Run the app on an Android emulator or a connected device.

## 🎨 Design

The app features a warm, book-inspired color palette, custom typography, and animated reading cards.
